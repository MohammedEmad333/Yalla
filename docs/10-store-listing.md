# 10 — بطاقة Google Play لتطبيق Yalla Delivery

آخر مراجعة: 2026-10-05

هذه نصوص مرجعية لبطاقة المتجر. قبل كل إصدار، طابقها مع المزايا المتاحة فعلًا في النسخة المرفوعة.

## اسم التطبيق

```text
يلا ديلفري - Yalla Delivery
```

## وصف قصير

```text
اطلب من المتاجر وتابع توصيلك بسهولة مع Yalla Delivery.
```

## وصف طويل

```text
Yalla Delivery يسهّل طلب احتياجاتك من المتاجر والمطاعم ومتابعة التوصيل من إنشاء الطلب حتى الوصول.

مع Yalla يمكنك:

• تصفح المتاجر والمطاعم والقوائم المتاحة.
• البحث عن المتجر أو الصنف واستخدام التصنيفات.
• إضافة الأصناف والخيارات والإضافات إلى السلة.
• حفظ العناوين واستخدامها عند إنشاء الطلب.
• متابعة حالة الطلب وتلقي الإشعارات المهمة.
• الاستفادة من العروض والكوبونات المتاحة.
• إعادة طلب طلبات سابقة مع إعادة التحقق من الأسعار والتوفر.
• تقييم تجربة التوصيل والمتجر بعد الطلب.
• التواصل مع الدعم عند وجود مشكلة مرتبطة بالطلب.

الدفع الإلكتروني للطلبات المدعومة يتم عبر Jawwal Pay، وفق التدفق المتاح داخل التطبيق.

للكباتن، يوفّر Yalla الأدوات اللازمة لاستقبال الطلبات المصرح بها ومتابعة حالة التوصيل والأرباح وفق الحساب والصلاحيات.

Yalla Delivery مصمم لتقديم تجربة عربية بسيطة وواضحة للطلب والتوصيل.
```

## روابط المتجر

- سياسة الخصوصية: `https://yalladelivery.org/privacy.html`
- حذف الحساب: `https://yalladelivery.org/delete-account.html`
- الموقع: `https://yalladelivery.org`

لا تستخدم رابط GitHub Pages القديم.

## ملاحظات الوصف

- لا تذكر ميزة كأنها متاحة لجميع المستخدمين إذا كانت خلف feature flag أو صيانة أو طرح تدريجي.
- لا تصف الدفع بأنه “من المحفظة فقط”؛ تدفق طلبات المتاجر الحالي يستخدم Jawwal Pay.
- لا تدّعِ زمن توصيل أو ترتيبًا مثل “الأسرع/الأفضل” دون أساس قابل للإثبات.
- حدّث النص إذا تغيرت طرق الدفع أو جمع البيانات أو أدوار التطبيق.

## الأصول الرسومية

تحقق من متطلبات Play Console الحالية وقت الرفع. الأصول المعتادة تشمل:

- أيقونة متجر عالية الدقة.
- Feature graphic.
- لقطات شاشة هاتف حديثة من النسخة الحالية.

يجب ألا تعرض اللقطات أرقام هواتف أو عناوين أو أكواد طلب أو بيانات شخصية حقيقية.
