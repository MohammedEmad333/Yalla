# سياسة الخصوصية — Yalla Delivery وYalla Partner

**آخر مراجعة للتوثيق:** 5 أكتوبر 2026

> النسخة العامة المنشورة التي يجب ربطها من التطبيقات والمتاجر هي: `https://yalladelivery.org/privacy.html`. هذا الملف مرجع نصي داخل المستودع ويجب أن يبقى متوافقًا معها ومع السلوك الفعلي للخدمات.

توضح هذه السياسة على مستوى تقني كيف تعالج خدمات Yalla Delivery وYalla Partner البيانات اللازمة لتشغيل الحسابات والطلبات والمتاجر والتوصيل والدفع والدعم.

## 1) نطاق الخدمات

يشمل ذلك:

- Yalla Delivery للعملاء والكباتن.
- Yalla Partner لأصحاب المتاجر والمطاعم والموظفين المصرح لهم.
- تطبيق/لوحة الإدارة والخدمات المساندة.
- مواقع Yalla وواجهات API المرتبطة بها.

## 2) البيانات التي قد نعالجها

| الفئة | أمثلة | الغرض |
|---|---|---|
| الحساب | الاسم، الهاتف، البريد الاختياري، معرّفات الجلسة | إنشاء الحساب، الدخول، الصلاحيات والدعم |
| الموقع | GPS ونقاط الاستلام/التسليم | تنفيذ التوصيل وتتبع الطلب النشط |
| الطلبات | الأصناف، الكميات، الأسعار، الحالة، العنوان، التقييم | إنشاء الطلب وتنفيذه وحفظ السجل |
| المتجر/الشريك | بيانات المتجر، المنتجات، الصور، التوفر، الموظفون | تشغيل Partner وإدارة المتجر |
| الرسائل والدعم | محتوى المحادثات المرتبطة بالخدمة عند استخدامها | التواصل وتنفيذ الطلب والدعم |
| الدفع | رقم محفظة جوال عند الدفع، المبلغ، حالة الدفع، مراجع العملية | تنفيذ ومطابقة دفعات Jawwal Pay والاستردادات |
| المحافظ والتسويات | الأرصدة، الأرباح، المعاملات، التسويات | العمليات المالية الداخلية |
| الصور والملفات | صور المنتجات ومرفوعات الميزات التي يختار المستخدم/الشريك إرسالها | تشغيل الميزة ذات الصلة |
| الإشعارات | FCM token | إرسال إشعارات الخدمة |
| بيانات تقنية وأمنية | IP، metadata للجلسات/الطلبات، logs لازمة للأمان والتشغيل | حماية الخدمة، التشخيص ومنع إساءة الاستخدام |

لا ينبغي تخزين OTP الخاص بالدفع في logs أو analytics كبيانات تطبيق عادية.

## 3) الموقع

قد يستخدم Yalla Delivery الموقع الدقيق عند الحاجة إلى تحديد نقطة الاستلام أو التسليم أو تتبع الكابتن أثناء تنفيذ طلب نشط. يجب أن تتوافق أذونات التطبيق مع الاستخدام الفعلي؛ لا توثق background location إذا لم يكن التطبيق يطلبه ويستخدمه.

## 4) كيف نستخدم البيانات

- إنشاء الحسابات والتحقق من الصلاحيات.
- تنفيذ الطلبات والتوصيل والتتبع.
- تشغيل المتاجر والقوائم وPartner.
- معالجة الدفع والاسترداد والتسويات.
- إرسال الإشعارات المتعلقة بالخدمة.
- تقديم الدعم وحل النزاعات والمشكلات المرتبطة بالطلبات.
- حماية الحسابات والخدمة ومنع إساءة الاستخدام.
- تشخيص الأعطال وتحسين الاستقرار.
- تلبية الالتزامات النظامية عندما تنطبق.

لا تُستخدم هذه الوثيقة كأساس لإضافة استخدام جديد للبيانات؛ أي استخدام جديد يحتاج تحديث المنتج والسياسة والإفصاحات المطلوبة.

## 5) مزودو الخدمة

قد تمر البيانات اللازمة عبر مزودي خدمة يستخدمهم Yalla، مثل:

- Oracle Cloud للاستضافة.
- Cloudflare للواجهات/CDN/DNS والحماية.
- Firebase Cloud Messaging للإشعارات.
- Jawwal Pay لمعالجة دفعات الطلبات والاستردادات المرتبطة بها.
- مزود البريد المهيأ في backend عندما تكون رسائل البريد مفعلة.
- خدمات خرائط/ملاحة عندما يفتح المستخدم الوظيفة المرتبطة بها.

يجب مشاركة الحد الأدنى اللازم لكل وظيفة وحماية credentials الخاصة بهذه الخدمات خارج المستودع.

## 6) المشاركة بين أطراف الطلب

قد تظهر للأطراف المخولة معلومات لازمة لإتمام الطلب، مثل موقع أو بيانات تواصل محدودة وفق مرحلة الطلب والصلاحيات. لا ينبغي عرض بيانات شخصية غير لازمة خارج سياق التنفيذ أو الدعم.

## 7) الاحتفاظ والحذف

تُحتفظ البيانات بالقدر اللازم لتقديم الخدمة وحفظ السجلات التشغيلية/المالية المطلوبة. عند طلب حذف الحساب، يطبق مسار الحذف المنشور وسياسة الاحتفاظ الفعلية على الخادم.

صفحة حذف الحساب الرسمية:

```text
https://yalladelivery.org/delete-account.html
```

لا تعد بحذف فوري لكل سجل إذا كان implementation أو التزام حفظ سجل مالي/أمني يتطلب معالجة مختلفة؛ يجب أن تتطابق الصياغة العامة دائمًا مع التنفيذ الحقيقي.

## 8) الأمان

- اتصالات الإنتاج تستخدم HTTPS.
- secrets ومفاتيح المزودين لا تُخزن في Git.
- رموز المصادقة على العميل تستخدم التخزين الآمن حيث يطبقه التطبيق.
- MongoDB لا يجب أن يكون مكشوفًا للعامة.
- مستندات الهوية والمرفوعات الحساسة لا تُخدم من مسار `/media` العام.
- صلاحيات الإدارة/الشريك تطبق في backend وليس UI فقط.

## 9) الأطفال

الخدمة ليست مصممة كمنتج موجه للأطفال. يجب أن تتوافق الفئة العمرية والتصريحات في المتاجر مع الجمهور الفعلي وسياسات المتجر السارية.

## 10) التغييرات

عند إضافة مزود دفع أو SDK analytics/crash/ads أو نوع بيانات جديد، راجع معًا:

- الصفحة العامة `site/privacy.html`.
- هذا الملف.
- `09-data-safety.md`.
- Play Console/App Store disclosures إن وجدت.

## 11) التواصل

استخدم بيانات التواصل الرسمية المنشورة على `yalladelivery.org` وصفحات المتجر. لا تضف عنوانًا شخصيًا أو credential إلى هذا الملف لمجرد وجوده في نسخة قديمة.
