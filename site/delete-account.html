تشرح هذه الصفحة كيفية طلب حذف الحساب بالكامل أو حذف بيانات محددة مع إبقاء الحساب في خدمات Yalla Delivery وYalla Partner، التي تديرها Yalla Delivery، وما البيانات التي تُحذف وما البيانات التي قد نحتاج للاحتفاظ بها لفترة محدودة لأسباب قانونية أو أمنية أو محاسبية.

1) حذف حساب Yalla Delivery من داخل التطبيق

  1. افتح تطبيق Yalla Delivery وسجّل الدخول.
  2. انتقل إلى صفحة «حسابي».
  3. اضغط «حذف الحساب».
  4. أكّد العملية. إذا لم يوجد طلب نشط يمنع الحذف، يتم تنفيذ الطلب وتسجيل خروجك.
قد لا يكون الحذف الفوري متاحًا أثناء وجود طلب نشط أو التزام مالي أو تشغيلي قائم. أكمل العملية القائمة أو تواصل معنا لمعالجة الطلب يدويًا.

2) حذف حساب Yalla Partner

يمكن لصاحب المتجر إنشاء حساب Yalla Partner وإرسال بيانات متجره للمراجعة من التطبيق. لا يظهر المتجر للزبائن قبل اعتماد الإدارة. لا يوفّر إصدار التطبيق الحالي زر حذف حساب ذاتي داخل التطبيق؛ يمكن لمالك المتجر أو الموظف المخوّل طلب حذف حسابه وبياناته من خلال وسائل التواصل أدناه.

عند طلب حذف حساب تاجر أو موظف، قد نحتاج إلى التحقق من ملكية الحساب أو صلاحية مقدم الطلب قبل التنفيذ، وذلك لحماية بيانات المتجر والطلبات والموظفين.

3) حذف بيانات محددة بدون حذف الحساب

يمكنك طلب حذف بيانات محددة مرتبطة بحسابك مع إبقاء الحساب فعالًا، متى كان حذف تلك البيانات لا يمنع تشغيل الخدمة ولا يتعارض مع التزامات قانونية أو محاسبية أو أمنية.

من أمثلة البيانات التي يمكن طلب حذفها أو إزالتها عند انطباق ذلك:

  • صور المنتجات أو صور المتجر التي قمت برفعها.
  • محتوى منتجات أو أوصاف أو خيارات لم تعد تريد الاحتفاظ بها.
  • بعض بيانات الملف الشخصي أو بيانات المتجر غير الضرورية لتشغيل الحساب.
  • محتوى آخر أنشأه المستخدم أو الشريك ولم يعد مرتبطًا بطلب نشط أو التزام قائم.

لطلب حذف بيانات محددة، أرسل لنا اسم الخدمة، رقم الهاتف المسجل، وحدد بوضوح البيانات التي تريد حذفها. سنراجع الطلب ونحذف البيانات أو نجهّلها إذا كان ذلك ممكنًا دون حذف الحساب بالكامل.

بحسب نوع الحساب والبيانات المرتبطة به، قد يشمل الحذف:

  • بيانات الحساب مثل الاسم ورقم الهاتف ومعلومات تسجيل الدخول المرتبطة بالحساب.
  • رموز الجلسات والإشعارات المرتبطة بالحساب عند انطباقها.
  • بيانات الملف الشخصي غير المطلوبة للاحتفاظ القانوني أو المحاسبي.
  • لحسابات Yalla Partner: بيانات حساب التاجر أو الموظف وصلاحياته بعد التحقق من إمكانية الحذف.
  • صور أو محتوى رفعه المستخدم أو الشريك إذا لم نعد بحاجة للاحتفاظ به لتشغيل خدمة قائمة أو للامتثال القانوني.

6) بيانات Yalla Partner والمتجر

عند طلب حذف متجر كامل، سنراجع البيانات المرتبطة به ونحذف أو نجهّل ما يمكن حذفه، وقد نحتفظ مؤقتًا بسجلات الطلبات أو المعاملات أو سجلات الأمان بالقدر المطلوب قانونيًا أو محاسبيًا.
